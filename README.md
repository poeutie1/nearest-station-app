# Nearest Station App

現在地から最寄り駅を探すWebアプリケーション

## 概要

GPSで取得した現在地から、最寄りの地下鉄駅を検索・表示するアプリです。
路線は違うけど歩いてすぐの駅を見つけたい、乗り換えを減らしたい人向け。

対応路線: 丸ノ内線・半蔵門線・有楽町線・千代田線・銀座線

## 主な機能

- 現在地からの最寄り駅検索
- 路線別の駅一覧表示
- Haversine式による距離計算

## 使用技術

- **フレームワーク**: Next.js (App Router)
- **言語**: TypeScript
- **スタイリング**: CSS Modules
- **ホスティング**: Vercel
